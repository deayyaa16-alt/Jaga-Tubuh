# JagaTubuh
Platform kesehatan digital berbasis web yang dirancang untuk membantu pengguna memahami kondisi tubuhnya secara mandiri. Mulai dari analisis kesehatan dasar, rekomendasi nutrisi, hingga konsultasi dengan tenaga profesional—semua bisa diakses dalam satu tempat.

## Fitur Utama
- **Beranda** – Halaman pembuka yang menampilkan data prevalensi kesehatan di Indonesia serta gambaran umum solusi yang ditawarkan JagaTubuh.
- **Cek Kesehatan** – Fitur inti yang memproses data pengguna (umur, berat badan, tinggi badan, tingkat aktivitas) untuk menghitung BMI, BMR, kebutuhan kalori harian, dan target makronutrisi secara otomatis.
- **Konsultasi Gizi** – Menyediakan daftar tenaga profesional dengan filter spesialisasi, simulasi chat, serta fitur pengaturan jadwal konsultasi.
- **Komunitas** – Forum diskusi tempat pengguna dapat saling berbagi cerita, memberi dukungan, dan tetap terhubung dengan sesama.
- **Dashboard Pengguna** – Ringkasan personal yang menampilkan progres kesehatan, rencana diet, dan insight yang disesuaikan dengan data terbaru pengguna.

## Teknologi yang Digunakan
Proyek ini dibangun dengan pendekatan frontend murni tanpa backend atau database eksternal.
- **HTML5** – Struktur dasar halaman.
- **CSS3 & Bootstrap 5** – Styling dan layout responsif.
- **JavaScript (Vanilla)** – Seluruh logika interaktif.
- **Font Awesome** – Ikon pendukung.
- **AOS (Animate On Scroll)** – Animasi saat scroll.
- **Local Storage** – Penyimpanan sesi dan data login sementara.

## Cara Menjalankan Secara Lokal
1. Unduh atau clone repositori ini ke perangkat Anda.
2. Pastikan seluruh folder dan file berada pada struktur yang sesuai.
3. Buka file `index.html` menggunakan peramban web (Chrome, Edge, Firefox).
4. Disarankan menggunakan **Live Server** agar seluruh file JavaScript dapat diakses tanpa hambatan.


## Rencana Pengembangan
Beberapa hal yang sedang dipersiapkan untuk pengembangan ke depan:
- Integrasi backend dan database untuk penyimpanan data permanen.
- Sistem rekomendasi menu berbasis data kalori makanan.
- Fitur chat real-time untuk konsultasi dengan tenaga profesional.
- Pengingat otomatis untuk jadwal konsultasi dan target harian pengguna.
